Expose automated junk heuristic kwarg-only flag `autojunk` from
:class:`difflib.SequenceMatcher` to the public functions
and class methods in the :mod:`difflib`. This option defaults
to ``True``, meaning that until now it was always implicitly "on"
in other methods and classes of :mod:`difflib` which are relying
on :class:`difflib.SequenceMatcher`.

See the :class:`difflib.SequenceMatcher` documentation for details
of this flag purpose and issue :gh:`118150` for the motivation.
