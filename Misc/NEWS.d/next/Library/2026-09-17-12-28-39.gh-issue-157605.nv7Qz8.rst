Fix a bug that caused :mod:`!_remote_debugging` sampling to fail entirely
with ``RuntimeError: Failed to parse initial frame in chain`` when a native
thread retained a Python thread state with an empty Python frame stack. The
base_frame sentinel is now accepted as a valid empty stack, and a first
frame without Python code followed by a valid continuation is handled like
a mid-chain native frame instead of failing the sample. Valid stacks from
other threads are now reported instead of being lost.
