.. cve: CVE-2026-115514

Fix the EUC-KR decoder to reject the 8-byte Hangul make-up sequence for
syllables that KS X 1001 encodes in 2 bytes, so that decoded names re-encode
to the same bytes and :mod:`tarfile` extraction filters cannot be bypassed
through symlinks on hosts using the EUC-KR filesystem encoding.
