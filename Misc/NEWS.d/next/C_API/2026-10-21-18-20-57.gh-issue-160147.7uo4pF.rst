Add a new :ref:`PySetBuilder <pysetbuilder>` C API to create a :class:`set`
object or a :class:`frozenset` object. Add functions:

* :c:func:`PySetBuilder_CreateSet`
* :c:func:`PySetBuilder_CreateFrozenSet`
* :c:func:`PySetBuilder_Finish`
* :c:func:`PySetBuilder_Discard`
* :c:func:`PySetBuilder_Add`
* :c:func:`PySetBuilder_AddSteal`
* :c:func:`PySetBuilder_Update`
* :c:func:`PySetBuilder_UpdateArray`
* :c:func:`PySetBuilder_UpdateArraySteal`
