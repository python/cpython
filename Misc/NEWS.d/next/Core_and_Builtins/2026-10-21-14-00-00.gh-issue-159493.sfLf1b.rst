Superinstructions are now formed after the compiler decides which
:opcode:`LOAD_FAST` instructions can borrow their reference. A borrowable
load is no longer fused into :opcode:`STORE_FAST_LOAD_FAST`, so the
bytecode for a loop body no longer depends on whether it is written on the
same line as the ``for`` statement. This fixes a reference count contention
slowdown on the free-threaded build for single-line loops and comprehensions.
